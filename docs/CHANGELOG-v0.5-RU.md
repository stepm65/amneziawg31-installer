# Изменения v0.5.0-test

- Интерактивный выбор в установщике: без reverse proxy / Nginx с самоподписанным TLS / Nginx с существующим PEM сертификатом и приватным ключом.
- Запрос домена или IPv4 для HTTPS, HTTPS-порта и путей к своим TLS-файлам.
- Проверка сертификата и соответствия приватного ключа до редактирования конфигурации Nginx.
- Генерация самоподписанного сертификата на 365 дней с SAN IPv4/DNS, приватный ключ 0600.
- Nginx reverse proxy на 127.0.0.1:порт-панели; ничего в FastAPI/awg0 не меняется.
- Проверка `nginx -t` и HTTPS `/health`. Если шаг не завершился, созданный сайт откатывается, VPN и веб-панель остаются установленными.
- Предусмотрена установка Nginx на Ubuntu 24.04/26.04 (APT) и Rocky 9/10 (DNF). Rocky: подтверждение настройки SELinux и индивидуальный выбор открытия порта в firewalld.
- При полностью отключённом IPv6 установщик корректирует только стандартный IPv6-listener **свежей** установки Nginx, сохраняя резервную копию. Существующий Nginx не переписывается.
- Позднее включение proxy: `sudo awg31 nginx`, без пересоздания VPN.

**Проверено:** Bash syntax, локальные Python-тесты, OpenSSL тесты SAN и совпадения ключей. **Ещё не проверено на реальном VPS:** Nginx+TLS в сочетании с Ubuntu 24.04/26.04 и Rocky 9/10; firewall/SELinux, второй интерфейс AWG. Используйте snapshot VM перед тестом.
