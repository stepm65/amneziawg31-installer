# AWG Console v0.7.0-test — обновление интерфейса

**Только веб-интерфейс:** `web.py`, `md3.css`, `panel.js`. Ни один VPN-интерфейс, ключ, маршрут, системная служба или настройка Nginx не изменяются этим обновлением.

## Что изменилось

- Удалён текстовый бейдж **KERNEL** из шапки; переключатель RU/EN сохранён.
- Основное меню расширено и разделено на рабочее пространство, конфигурацию и систему. На ПК оно сворачивается до иконок, на телефоне открывается выдвижной панелью.
- В «Обслуживании» появилась собственная навигация: Диагностика, Резервные копии, Восстановление, Профили сервера, Безопасность, Журнал действий, Система. На ПК это вертикальное меню, на мобильном — горизонтально прокручиваемые вкладки.
- Диагностика отображает счётчик успешных проверок и карточки с деталями для ядра, модулей, DKMS, интерфейса, IPv4 forwarding, Secure Boot и служб. Детальный системный вывод спрятан в раскрываемые секции. Состояния получаются из существующего контроллера, не подменяются демонстрационными.
- Формы создания/скачивания бэкапа, восстановления, импорта профиля и смены пароля доступны по прежним защищённым маршрутам. Подтверждения и CSRF остаются обязательными.

## Обновление уже работающей v0.6.1-test

```bash
cd /root/awg31-update
git pull --ff-only origin main
sudo bash scripts/upgrade-ui.sh
curl --noproxy '*' -fsS http://127.0.0.1:8080/health
```

Скрипт `upgrade-ui.sh`:

1. Проверяет установленную панель и синтаксис Python.
2. Сохраняет текущие `web.py`, `md3.css`, `panel.js` в каталог с правами root `0700` внутри `/var/backups/awg31-ui.*`.
3. Заменяет только три файла и перезапускает службу `awg31-panel.service`.
4. Проверяет `/health` на реальном порту панели. При неудаче возвращает предыдущие версии файлов и перезапускает панель.

**Ни в коем случае не выполняйте `install.sh` на уже работающем VPN**. Модуль, клиентов и конфигурации повторно устанавливать не нужно.

После обновления принудительно обновите страницу в браузере (`Ctrl+Shift+R`). При неизвестных ошибках сохраните вывод `journalctl -u awg31-panel -n 100 --no-pager`.

## Ограничения

Изменена только визуализация: диагностика не подписывает автоматически модуль, восстановление остаётся операцией с остановкой VPN, а вкладка «Система» лишь показывает безопасные команды обслуживания. Установка и мультисерверность на Rocky по-прежнему требуют реального тестирования.
