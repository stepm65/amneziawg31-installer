# v0.5.1-test

- Опциональные клиентские I1-I5; по умолчанию отключены, не включаются в экспорт .conf или QR.
- Индивидуальный редактор клиентского I-профиля.
- Отдельный список IPv4-префиксов за клиентом (включая одиночные IPv4 /32) с обновлением серверного AllowedIPs, маршрутов Linux и scoped iptables FORWARD.
- Поддержка старых SQLite баз: автоматическое добавление колонок без пересоздания клиентов.
- Проверка пересечений LAN и VPN маршрутов, включая другие остановленные AWG-инстансы.
- Резервные копии перед изменениями профилей клиентов.
- Редактор клиента RU/EN, Material 3 графит/янтарь.
- Автотесты без обращения к действующему ядру; маршрутизация и поведение QR требуют проверки на реальном сервере.
