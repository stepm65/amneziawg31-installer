# Обновление веб-интерфейса AWG Console v0.1.5-test

Визуальный стиль: графитовый / почти чёрный, янтарный акцент, компактное боковое меню и карточки. RU/EN сохранены.

**Обновление затрагивает только `/opt/awg31-panel/web.py`, `/opt/awg31-panel/panel.css` и `/opt/awg31-panel/panel.js`**. Контроллер, база клиентов, серверные ключи, `/etc/amnezia/...`, параметры `awg0` и VPN-сервис не изменяются.

1. Скопируйте ZIP на сервер, распакуйте в отдельный каталог.
2. Выполните от root `bash scripts/upgrade-ui.sh`.
3. Скрипт создаст резервную копию в `/var/backups/awg31-panel-ui.*`, перезапустит только `awg31-panel` и проверит `/health`, CSS и JS через `curl --noproxy '*'`. При неуспешной проверке старые UI-файлы восстанавливаются.
4. Проверьте `systemctl status awg31-panel --no-pager` и `curl --noproxy '*' http://127.0.0.1:8080/health`. Если панель на другом порту, укажите `PANEL_PORT=...`.
5. В браузере через Nginx HTTPS сделайте жёсткую перезагрузку страницы (Ctrl+Shift+R).

Появился мониторинг RX/TX: опрос защищённого `/api/traffic` каждые 4 секунды, построение графика по разнице счётчиков **только пока открыта вкладка**. Это не система длительного хранения метрик: после обновления страницы график начинается заново. Трафик подсчитывается по AWG peer-статистике. Статус «подключено» означает handshake за последние 3 минуты.

Таблица клиентов получила поиск по имени/IP и фильтр активных. Сохранены операции создания, включения, отключения, скачивания конфигураций и QR-кода.

**Примечание**: маршрутизация Xray, геобазы, подписки и балансеры не относятся к управлению сервером AmneziaWG и сюда не включены.

Тестовая версия: тесты и синтаксические проверки проведены локально; интерфейс и график ещё не проверены на вашем сервере. Не проводите обновление во время критических VPN-сессий.
