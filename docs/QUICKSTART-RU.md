# Quick Start AmneziaWG 3.1 (Ubuntu 24.04/26.04, Rocky Linux 9/10)

**Состояние: v0.5.0-test — только для тестового VPS, без публикации стабильного релиза.**

После создания публичного GitHub-репозитория **и загрузки проверенного Release** появится команда:

```bash
curl -fsSL https://raw.githubusercontent.com/stepm65/amneziawg31-installer/main/bootstrap.sh | sudo bash
```

**Команда пока не работает**, потому что указанный публичный релиз ещё не опубликован. Нельзя запускать её до проверки кода и публикации Release с контрольной суммой.

## Как проверить уже сейчас

Распакуйте полученный тестовый ZIP на чистую Ubuntu 24.04/26.04 или Rocky 9/10 и выполните:

```bash
cd amneziawg31-ubuntu-installer
sudo bash bootstrap.sh
```

Всё остальное выполняет один мастер: пакеты Ubuntu, исходники модуля ядра, DKMS, инструменты AWG 3.1, настройка сети, systemd и панель. Установщик не включает IPv6, не использует Docker и PPA.

Он спросит VPN-подсеть, UDP-порт, MTU, DNS, Endpoint, внешний интерфейс, режим full/split (по умолчанию full, весь IPv4 через VPN), localhost-порт панели и имя первого клиента; затем спрашивает Nginx (без прокси, самоподписанный TLS или путь к собственному сертификату), домен/IP и HTTPS-порт, а также пароль администратора.

### Secure Boot

При включённом Secure Boot Ubuntu может запросить пароль MOK для DKMS-модуля. Это единственный обязательный дополнительный шаг: на экране загрузки через **консоль VM** выберите **Enroll MOK**, подтвердите пароль и перезагрузитесь. После этого **повторите ту же команду**. DKMS-пакет не пересобирается заново, а мастер продолжает установку. Автоматически отключать Secure Boot скрипт не будет.

### Существующая установка и обновления

Уже работающий `awg0` защищён от повторной инициализации:

```bash
sudo bash bootstrap.sh --upgrade
```

Эта команда обновляет только контроллер и веб-панель; существующие ключи и конфигурации сохраняются. Перед тестовым обновлением сделайте snapshot VM. Можно также проверить установленное окружение:

```bash
sudo bash bootstrap.sh --doctor
```

Управление после установки: `sudo awg31`, `sudo awg31 status`, `sudo awg31 logs`.

### Безопасность загрузки

После публикации bootstrap скачивает архив из **GitHub Releases** и сверяет `.sha256`. Код, полученный по HTTPS, всё равно запускается от root: проверяйте адрес и содержимое скрипта, особенно если повторяете команду из стороннего источника. Источники модуля и инструментов фиксированы конкретными версиями. В проект включён патч совместимости [AmneziaWG PR #265](https://github.com/amnezia-vpn/amneziawg-linux-kernel-module/pull/265), который был успешно применён на тестовом Ubuntu 26.04.1 / 7.0.0-43-generic.

### Ограничения текущего тестового релиза

- Сборка модуля на других ядрах не гарантирована.
- При проблемах с сетью GitHub/PyPI/APT установка остановится.
- Тестовая панель пока требует проверки создания второго интерфейса и полного handshake + NAT.
- В Linux с nftables/UFW нестандартные правила firewall могут требовать ручной настройки.
- IPv6 на клиентах не туннелируется и потенциально может обходить VPN.

## Операционные системы и Secure Boot (v0.5.0-test)

| ОС | Способ установки пакетов | Состояние |
|---|---|---|
| Ubuntu 24.04 LTS | APT + DKMS + linux-headers текущего ядра | экспериментально; без теста на VPS |
| Ubuntu 26.04 LTS | APT + DKMS + патч Ubuntu PR #265 | модуль и панель проверены на 7.0.0-43; Quick Start v0.4 требует проверки |
| Rocky Linux 9/10 | DNF + CRB/EPEL + kernel-devel текущего ядра | экспериментально; без теста на VPS |
| Rocky Linux 8 | — | не поддерживается в этой сборке |

Secure Boot **отключён**: MOK не требуется, проверяем `modprobe amneziawg`.
Secure Boot **включён**: DKMS подпись/регистрация MOK; при отказе загрузки подтвердите ключ в MOK Manager через консоль, повторите ту же Quick Start команду. Secure Boot автоматически не отключается.

На Rocky Linux с включённым firewalld мастер предупредит о возможном конфликте с iptables Full Tunnel и запросит явное подтверждение для продолжения. Для интернет-трафика необходимо отдельно проверить firewalld policy/NAT и UDP разрешения. Процедура пока не прошла испытания на Rocky и не должна считаться готовой для production.

Веб-панель: Material Design 3 style с прежней графитовой + янтарной палитрой, RU/EN и локальными CSS/JS. Мастер умеет опционально установить Nginx и HTTPS; подробности в [NGINX.md](NGINX.md).
