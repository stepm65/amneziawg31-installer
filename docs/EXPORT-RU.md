# Экспорт конфигурации AmneziaWG 3.1

В панели откройте **Клиенты → Конфигурация**. Есть две вкладки:

- **.conf** — полный текст конфигурации AWG 3.1, QR, кнопки копирования, скачивания `.conf` и PNG.
- **AmneziaVPN Link** — ссылка `vpn://…` с контейнером `amnezia-awg2` и `protocol_version=3.1` в JSON, QR, копирование и скачивание `.vpn`.

Ссылка `vpn://` формируется по JSON-схеме клиента AmneziaVPN и кодируется URL-safe Base64 без сжатия. **Это экспериментальный экспорт:** его нужно проверить реальным импортом на Android/iOS/desktop-приложениях, прежде чем считать готовым к эксплуатации. Если импорт не сработал, используйте `.conf`.

`I1–I5` в стандартном AWG 3.1 не обязательны и по умолчанию отсутствуют. Для full-tunnel только IPv4 используется `AllowedIPs = 0.0.0.0/0` без `::/0`.

**Конфигурации, QR и ссылки содержат приватные ключи клиентов.** Не публикуйте их, не вставляйте в баг-репорты, не пересылайте в открытые каналы и не размещайте в публичном GitHub. Страницы защищены авторизацией, отдаются с `Cache-Control: no-store`.

Обновление с предыдущей версии: скопировать исходники, затем выполнить `sudo bash scripts/upgrade-core.sh` на рабочем сервере. Скрипт не должен перезапускать awg0, но требует предварительного snapshot.
