# Изменения 0.2.0-test

- Поддержка независимых интерфейсов `awg0` … `awg99` с лимитом **8 серверов** на VPS, отдельными конфигурациями, клиентами, ключами, UDP-портами, подсетями и службами `awg-quick@...`.
- Кнопка **Сгенерировать параметры AWG 3.1** без немедленного применения.
- Редактирование `Jc/Jmin/Jmax`, `S1–S4`, `H1–H4`, `HeaderProtectionKey`, `ContentPaddingAddition`, `RandomTrailers`, `DisableCookies`, таймеров.
- Проверка диапазонов, пересечений заголовков и длины ключа (base64, 32 байта).
- Проверки конфликтов UDP-портов и подсетей (включая маршруты хоста), предупреждение о переимпорте конфигураций.
- Остановка и запуск каждого интерфейса, удаление дополнительного сервера только без клиентов и с резервным копированием.
- Экспериментальное обновление `scripts/upgrade-core.sh` с откатом файлов панели и прав sudo при неуспехе.
- Существующий `awg0` и его база данных сохраняют прежние пути, обновление не меняет VPN-конфигурацию автоматически.
- Автоматизированные тесты: 20. Новые функции **ещё не проверены на реальном VPN-сервере**.

## Невыполненное / ограничения

- Пока не реализованы отдельные визуальные редакторы CPS-пакетов `I1`–`I5` (клиентская имитация), мультихоп, Xray-правила/балансеры и долговременная статистика.
- Проверка на Ubuntu 26.04.1 пройдена для модуля ядра, базового `awg0` и ранее установленной веб-панели. В этом релизе второй интерфейс, генератор параметров и изменение обфускации пока не проверены с реальным клиентом.
- `S/H` и `HeaderProtectionKey` должны совпадать на сервере и клиенте. После изменения нужно перевыпустить профили клиентов соответствующего сервера.
