# AmneziaWG Console 0.6.0-test

## Пять добавленных блоков

1. Клиентские политики: дата истечения UTC, комментарий, лимит суммарного полученного и отправленного трафика; проверка системным таймером раз в минуту.
2. Историческая статистика: 24ч/7д/30д, хранение 32 дня, отдельный авторизованный JSON endpoint. Накопление начинается после установки.
3. Настройки/профили: экспорт и импорт JSON без приватных ключей; резервные полные tar.gz архивы с SQLite, серверными конфигурациями, данными администратора и SHA256-манифестом. Все архивы доступны только авторизованному пользователю по HTTPS.
4. Безопасность: смена пароля, инвалидирование старых сессий, аудит, ограничения входа, CSRF и закрытая привилегированная команда для скачивания.
5. Обслуживание: сведения о ядре, DKMS, Secure Boot, интерфейсе, systemd; самопроверка через systemd.timer после старта и ежедневно.

## Ограничения тестовой версии

- Резервные копии в tar.gz содержат секреты и не шифруются дополнительно. Безопасно храните скачанный архив.
- Restore в веб-интерфейсе отсутствует: для восстановления ключей/БД нужна консоль и план обслуживания, чтобы не оборвать SSH-туннель.
- Лимиты — суммарный RX+TX, не скорость передачи; обнуления потребления нет. Возможное превышение лимита до следующей минутной проверки.
- Данные до первой выборки недоступны, история очищается через 32 дня.
- Secure Boot / DKMS-проверка диагностическая, она не переподписывает драйвер.
- Обновление v0.6 на VPS и создание резервных копий на живом сервере ещё требуют тестирования.

## Проверка после обновления

```bash
sudo systemctl status awg31-panel awg31-sampler.timer awg31-kernel-check.timer --no-pager
sudo /usr/local/sbin/awg31mgr sample-all
sudo /usr/local/sbin/awg31mgr backup-create
sudo awg31 doctor
```

Панель: `https://ВАШ-ДОМЕН/maintenance` (если настроен Nginx HTTPS).
