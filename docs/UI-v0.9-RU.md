# Интерфейс AmneziaWG Console v0.9.0-test

## Почему изменено

Предыдущая версия использовала слишком много однотипных карточек, повторяла заголовки и предлагала два разных механизма выбора сервера. В этой версии сделано **одно** место выбора VPN-интерфейса — ссылки на экземпляры в боковой панели, без выпадающего списка.

## Новая навигация

- **Обзор** (`/`) — все интерфейсы в одной компактной таблице; под ней краткие сведения о системе и ссылка на диагностику.
- **Все серверы** (`/servers`) — добавление, запуск, остановка и удаление дополнительного интерфейса.
- **Экземпляры** в sidebar — явный список `awg0`, `awg1`, `awg2` с подсетями и индикаторами работы.
- После выбора, например, `awg1` — **Обзор**, **Клиенты**, **Трафик**, **Настройки** в горизонтальных вкладках. Все URL начинаются с `/servers/awg1/`.
- **Обслуживание** — самостоятельные вкладки диагностики, резервных копий, восстановления, профилей, безопасности, аудита и системы. В диагностике сведения сгруппированы, разворачиваются для просмотра полного вывода.

Сервер не выбирается через cookie для операций над клиентами. URI всегда содержит интерфейс, поэтому разные вкладки браузера могут работать с разными AWG-серверами.

## Обновление v0.8.x до v0.9.0-test

Сделайте snapshot VPS (особенно для тестовой версии) и выполните:

```bash
cd /root/awg31-update
git pull --ff-only origin main
sudo bash scripts/upgrade-ui.sh
systemctl is-active awg31-panel
curl -fsS http://127.0.0.1:8080/health
```

Обновление копирует оригинальные файлы веб-интерфейса в `/var/backups/awg31-ui.*`, затем перезапускает **только** `awg31-panel`. При ошибке health-check скрипт восстанавливает прежний UI. VPN-интерфейсы, DKMS, ключи, Nginx, NAT и SQLite не трогаются.

Для панели старше v0.8 сначала обновите backend через `scripts/upgrade-core.sh` и только после этого примените UI.

После обновления выполните Ctrl+Shift+R в браузере для сброса кеша. Если дизайн неожиданно выглядит старым, проверьте URL `/assets/md3.css?v=0.9.0`.

## Проверки

Протестированы HTML-маршруты, изоляция интерфейсов, безопасность CSRF и действий, обновление CSS/JS, вид ПК при 1512px и телефона при 390px. Тестовые данные в скриншотах фиктивные. Работа на реальном VPS должна быть проверена отдельно.
