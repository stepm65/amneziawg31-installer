# Изменения

Здесь — что нового в каждом выпуске. Скрипт выпуска берёт раздел своей версии в текст релиза на GitHub.
English: [CHANGELOG.md](CHANGELOG.md).

## [0.29.0] — 2026-11-28

- **Список изменений в релизах:** этот файл и его английская версия; текст релиза на GitHub собирается из раздела своей версии.
- **Подпись выпусков:** для архива выпуска публикуется аттестация GitHub (происхождение сборки). Проверка: `gh attestation verify awg31-console-vX.Y.Z.tar.gz --repo stepm65/amneziawg31-installer`; установщик делает её сам с `AWG31_ATTESTATION=require`.
- **Руководство «Что делать, если…»** ([docs/TROUBLESHOOTING.ru.md](docs/TROUBLESHOOTING.ru.md)): модуль после смены ядра, забытый пароль или имя, потерянный TOTP или ключ доступа, заблокированный порт или IP, переезд на новый сервер, неудачное обновление и другое.

## [0.28.0] — 2026-11-28

- **Расписание доступа клиента:** дни, время «с»–«до» и часовой пояс; вне окна клиент отключается сам и включается обратно. Окна через полночь.
- **Запросы доступа в боте** (по желанию): незнакомый человек нажимает «Запросить доступ», администратор — «Выдать» или «Отклонить»; выдача создаёт клиента по шаблону и делает человека владельцем.
- **Сообщение владельцам** из бота (кнопка «📣 Рассылка») и из панели, с кнопкой «Мои подключения» по желанию.

## [0.27.0] — 2026-11-28

- **Проверка резервных копий по расписанию** (раз в неделю или каждую): как при восстановлении, плюс сравнение копии во внешнем хранилище байт в байт; уведомление в бот при ошибке; `sudo awg31 backup-verify`.
- **Срок хранения истории трафика** настраивается (серверы 32 дня, клиенты 62, от 7 до 730); базы сжимаются раз в неделю, кнопка «Сжать сейчас», `sudo awg31 db-vacuum`.
- **Метрики для Prometheus** по токену: серверы, клиенты, трафик, резервные копии; «Обслуживание → Мониторинг».

## [0.26.0] — 2026-11-28

- Своё имя для входа в панель: мастер установки спрашивает его вместе с паролем (`AWG31_ADMIN_NAME`); переименование учётных записей; `sudo awg31 reset-password` показывает и меняет имя.

## [0.25.0] — 2026-11-28

- Вход по ключу доступа (passkey, WebAuthn): отпечаток, лицо или PIN устройства вместо пароля и кода. Без новых зависимостей.

## [0.24.0] — 2026-11-28

- Несколько учётных записей панели с ролями «администратор» и «наблюдатель»; имя учётной записи в журнале действий и уведомлениях бота.
- Список активных сессий с завершением любой; «Выход» завершает только текущую сессию.

## [0.23.0] — 2026-11-28

- Удаление снимков отката (панель и `awg31 rollback delete`).
- График трафика клиента за 24 часа, 7 и 30 дней.
- Одноразовая ссылка на конфигурацию для человека без Telegram.

## [0.22.0–0.22.1] — 2026-11-28

- Мастер установки на экранах whiptail: язык, один экран параметров, проверка перед установкой, полоса прогресса с журналом; домен сервера в мастере.

## [0.21.0] — 2026-11-28

- Импорт клиентов из wg-easy, 3x-ui, AmneziaVPN и любого `.conf`: в панели с предпросмотром и `sudo awg31 import`.

## [0.20.0] — 2026-11-28

- Владельцы с несколькими устройствами и общими лимитами (трафик, срок, максимум устройств), самодобавление устройства в боте.

## [0.19.7–0.19.8] — 2026-11-27

- Понятные единицы на графиках трафика; необязательный домен сервера в конфигурациях вместо IP.

## [0.19.0–0.19.6] — 2026-11-22

- Группы клиентов и фильтры, сигнал о блокировке, рассылка новых конфигураций владельцам после изменения настроек; новый вид консоли; раздельные ограничения скорости на скачивание и загрузку.

## [0.18.0] — 2026-11-22

- Новые конфигурации владельцам после смены параметров, перенос клиента на другой сервер, случайная подсеть, профили Steam и «Свой».

## [0.17.0] — 2026-11-22

- Подписка для роутеров по HTTPS, смена порта и обфускации кнопкой и по расписанию, профили маскировки, проверка входящих пакетов, clamp MSS, защитные sysctl.

## [0.16.0] — 2026-11-20

- Снимок перед каждым обновлением и `awg31 rollback`, обновление и откат из панели, проверка всех страниц в браузере под CSP.

## [0.15.0] — 2026-11-20

- Приглашение в бот по одноразовой ссылке, перевыпуск ключа клиента, резервные коды TOTP, действия с отмеченными клиентами, выгрузка в CSV.

Более ранние выпуски — в истории коммитов.
